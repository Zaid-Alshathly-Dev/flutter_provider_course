# 🚀 Mastering Provider in Flutter - Course Practice

مستودع يحتوي على التطبيقات العملية والتحديات الخاصة بكورس **إدارة الحالة (State Management)** باستخدام حزمة **Provider** في Flutter (تقديم المهندس وائل أبو حمزة).

---

## 📌 عن المشروع (About the Project)
الهدف من هذا المستودع هو توثيق تقدمي وتطبيقي العملي خطوة بخطوة لجميع المفاهيم الأساسية والمتقدمة لإدارة الحالة في فلاتر، لضمان بناء تطبيقات ذات أداء عالٍ وهيكلية كود نظيفة (Clean Architecture).

---

## 🛠️ التقنيات المستخدمة (Technologies)
* **Framework:** [Flutter](https://flutter.dev/) 🚀
* **Language:** [Dart](https://dart.dev/) 🎯
* **State Management:** [Provider](https://pub.dev/packages/provider) 📦

---

## 📖 المفاهيم التي تم تطبيقها (Concepts Covered)

خلال رحلتي في هذا الكورس، قمت بتطبيق المفاهيم التالية:

- [x] **المقدمة (Introduction):** فهم الـ Local vs Global State ولماذا نحتاج إدارة الحالة.
- [ ] **ChangeNotifierProvider & ChangeNotifier:** إرسال البيانات وتحديث الواجهات عند التغيير.
- [ ] **Consumer:** استهلاك البيانات وتحديث أجزاء محددة فقط من الواجهة لتحسين الأداء.
- [ ] **Selector:** تحسين الأداء بشكل أدق عبر مراقبة حقول معينة فقط داخل الكائن.
- [ ] **Provider.of(context):** متى نستخدمها والفرق بينها وبين الـ Consumer.
- [ ] **MultiProvider:** تنظيم وإدارة أكثر من Provider في نفس الوقت بكود نظيف.
- [ ] **الأنواع المتقدمة:** 
  - [ ] FutureProvider
  - [ ] StreamProvider
  - [ ] ProxyProvider (لربط بروفايدر بآخر)

## 💻 كيف تقوم بتشغيل المشروع محلياً؟ (How to Run Locally)

1. قم بعمل Clone للمستودع:
   ```bash
   git clone [https://github.com/YourUsername/flutter_provider_course.git](https://github.com/YourUsername/flutter_provider_course.git)
2. اذهب إلى مجلد المشروع:
   ```bash
   cd flutter_provider_course
3. قم بتثبيت الاعتماديات (Dependencies):
   ```bash
   flutter pub get
4. شغل التطبيق:
   ```bash
   flutter run
```
